# Witch’s Potion Lab artwork

The supplied PNGs in this folder are required game artwork. Characters, cauldrons and animals render directly from these originals; no substitute CSS drawings appear during loading.

| File | Use |
| --- | --- |
| lab-background.png | Background, cover fit |
| witch-neutral.png | Witch during introduction and play, contain fit |
| witch-happy.png | Celebrating witch on the final screen |
| cauldron-normal.png | Cauldron during play |
| cauldron-bubbling.png | Cauldron while brewing |
| ingredient-tile.png | Word card background; words remain HTML text |
| mouse-one.png | Individual mouse, repeated to animate exactly five mice |
| mice-five.png | Group illustration in the final summary |
| goose-one.png | Individual goose, repeated to animate exactly four geese |
| geese-four.png | Group illustration in the final summary |
| sheep-one.png | Individual sheep, repeated to animate exactly six sheep |
| sheep-six.png | Group illustration in the final summary |

Use transparent backgrounds for characters, cauldrons and animals. Group images should contain exactly the named number of animals. During multiplication, the individual animal image is repeated, so animals appear one by one without duplicating the starting animal.
